# DSH Session Manager

DSH 侧栏插件：在工作区里用嵌套文件夹整理会话。

文件夹只是界面上的分组，数据存在浏览器本地。会话本身、DSH 安装目录、工作区成员关系都不会被修改；关闭插件后回到原生列表，分组数据保留。

## 功能

- **文件夹**：工作区下可建任意层级的文件夹。单击展开/折叠，双击或 F2 重命名，右键打开操作菜单。图标按层级循环三种颜色，可在设置 → 会话管理中自定义。
- **快速归档**：悬停会话行时，更多按钮旁有归档按钮（已归档会话显示恢复）。
- **移动**：把会话或文件夹拖到文件夹或工作区行上。Ctrl/Cmd 点选、Shift 范围选，可以批量拖动。只能在同一工作区内移动。
- **撤销**：焦点在侧栏树上时，Ctrl/Cmd+Z 撤销最近的移动（本次页面内最多 30 步）。改名、展开、创建、删除不进入撤销历史。
- **置顶**：置顶只在所在文件夹内生效，会话不会被拉到工作区根目录。
- **活动摘要**：文件夹右侧显示子孙会话中等待处理、运行中、完成未读的数量；工作区行显示该工作区全部会话的汇总（折叠时也显示）；顶部「工作区」标题显示所有工作区（含未分组）的总数。全部空闲时不显示，不计归档会话、独立子代理和空白草稿。点击某个计数可跳到对应会话：只有 1 个时直接打开，多个时弹出菜单列出标题和所在位置（按最近更新排序，底部显示空闲数和总数）。跳转会展开它所在的工作区和文件夹并滚动定位。侧栏很窄时只显示优先级最高的一项。
- **分页**：每个文件夹默认显示 5 个会话，可逐次展开更多。正在运行、待处理、完成未读和当前打开的会话会优先显示。
- **归档**：顶部 more →「已归档」让归档会话以灰色混入原位置，恢复后才能打开。
- **搜索**：顶部搜索或 Ctrl/Cmd+K，在标题、工作区名和会话正文中检索，Esc 返回树。
- **删除文件夹**：连同子文件夹一起删除，会话可以选择移回工作区根目录，或者先归档再删除。运行中的会话不会被强制停止。
- **键盘**：方向键/Home/End 移动焦点，Enter 打开或展开，左右键折叠/展开文件夹。

新建会话、打开会话、重命名会话、归档、恢复、置顶都调用 DSH 原生功能。

## 安装与更新

把仓库克隆到本地，然后在 Desktop 左侧「插件」→「安装第三方插件」→ 输入仓库根目录（`package.json` 所在目录）的本地路径 →「安装」并启用。

本地目录安装会直接链接到源码目录，启用期间不要移动或删除这个目录。

更新代码后先运行 `node build.cjs`，再**完全退出 Desktop（包括托盘）并重启**，否则会继续使用旧模块。

想临时回到原生列表：设置 →「会话管理」→ 关闭「使用树状列表」。分组数据保留，可随时切回。

## 数据

分组存在 `localStorage` 里：

| 键 | 内容 |
| --- | --- |
| `dsh.session-manager.v1` | 文件夹（ID、所属工作区、父文件夹、名称）、会话 ID → 文件夹映射、展开状态 |
| `dsh.session-manager.tree-view` | 是否使用树状列表 |

- 数据只在当前浏览器 origin 内有效，不跨设备、不跨端口同步。清除站点数据会丢失分组。
- 数据不含会话内容。已不存在的会话不显示，但映射保留，不会自动清理。
- 多个窗口会同步修改。如果检测到其他窗口已经写入，当前操作会被拒绝，载入最新数据后需要重试。
- 存储数据损坏时插件保留原生列表，不覆盖已有数据。

## 限制

- 适配的是 DSH 0.2.1-rc.2。重命名和归档通过原生侧栏 slot 内部取得回调，DSH 升级后可能失效；失效时插件会自动退回原生列表。
- 树状列表是插件自己渲染的，没有原生会话行的全部装饰和扩展菜单。需要这些功能时请切回原生列表。
- 「未分组」（不属于任何工作区的会话）只能浏览，不能建文件夹，也不能接收拖动。
- 批量归档不是事务：中途失败时，已归档的会话保持归档，文件夹和映射保留。
