# DSH Session Manager

独立 DSH 插件 `dsh-session-manager`，版本 0.1.7。为侧栏工作区增加嵌套文件夹；不修改 DSH 安装文件、会话日志格式或工作区成员关系。

## 使用

- 工作区/文件夹行悬停显示原生 more 与新建会话图标；more 菜单提供新建文件夹/会话，文件夹还有重命名/删除。
- 标题 14px/20px、会话行 32px、工作区/文件夹行 34px，使用原生字体变量、主题颜色、Menu、StateDot 和图标；普通空闲会话不显示灰点。文件夹图标按层级循环使用主题蓝/琥珀/绿。
- 每个工作区根目录和文件夹各默认展示 5 条非空会话，点击「展开其余 n 个会话」每次多展示 5 条；全部展示后可收起。空白草稿不占名额，前 50 条内当前/运行/待处理/完成未读会话可自动提高可见数量，避免隐藏需要关注的会话。
- 单击文件夹展开/折叠，双击重命名；双击会话调用 DSH 原生重命名弹窗。
- Ctrl / Cmd 点选切换选择，Shift 范围选，Ctrl / Cmd + Shift 累加范围；拖动会话或文件夹到文件夹/工作区行。
- 会话置顶只影响所在文件夹的同级会话，不会被拉到工作区根目录。文件夹排在会话之前。
- 侧栏树获得焦点时 Ctrl / Cmd + Z 撤销最近移动，不再占用 more 菜单；输入框保留自身撤销。最多保存本次页面生命期内 30 次移动。
- 顶部 more →「已归档」把归档会话混入原工作区/文件夹的正常排序，文字使用原生 `--dsw-alias-label-caption` 灰色，不另开区域；再点「隐藏已归档」隐藏。归档会话不显示置顶或状态点，通过 more →「恢复」恢复后才能打开。默认隐藏归档。
- 顶部搜索或 Ctrl / Cmd + K 在文件夹视图内展开输入框，不自动切到原生列表。合并本地标题/工作区匹配与原生 `sessions.search` 正文结果，250ms 防抖、取消旧请求，最多显示20条，结果过多时提示缩小范围。Esc/关闭恢复分组树。搜索结果暂为平铺列表，保留工作区名称和正文摘要，不修改分组。
- 子文件夹图标与父层会话标题对齐，每层增加 20px。文件夹新建/重命名使用原生 Modal、按钮和关闭/聚焦机制，输入名称自动全选。
- 删除文件夹必须选择「移至工作区根目录」或「归档会话并删除」，包含所有子文件夹。前者只删除分组；后者调用原生归档接口。
- 设置 →「会话管理」→「使用树状列表」：默认开启；关闭使用原生列表，保留原生工作区管理等入口。选择保存在 `localStorage` 键 `dsh.session-manager.tree-view`，刷新后保留并同步同源窗口。切换不丢分组和展开状态，但会清空当前多选。侧栏底部不再显示切换入口。
- 支持方向键/Home/End 移动焦点、Enter 打开/展开、左右键展开/折叠文件夹、F2 重命名。

## 安装

本次交付为**已构建的独立插件目录，未自动安装进当前 Desktop**。当前会话没有可用的 `plugin_manager` 工具；没有手工改 profile 或使用替代命令绕过插件管理器。

DSH 插件开发文档要求通过 `plugin_manager` 安装 bundle。在具备该工具的会话中，安装参数为：

```json
{"action":"install_bundle","target":"E:\\Root\\dsh-session-manager"}
```

已根据本机源码确认图形入口：左侧「插件」→「安装第三方插件」→ 输入本地目录 `E:\Root\dsh-session-manager`（不加引号）→「安装」/「立即启用」。本次未通过浏览器执行安装。安装本地目录通常链接到源码目录，启用期间不要移动或删除。插件无 npm 依赖、安装脚本或额外服务。

更新后重新运行构建；完整退出 Desktop（包括托盘）并重启，避免复用旧 Client 模块。禁用/卸载会撤销侧栏覆盖并恢复原生列表，分组数据保留。

## 数据与决策

| 问题 | 本版决策 | 其他路径与取舍 |
| --- | --- | --- |
| 分组保存位置 | 浏览器 `localStorage` 键 `dsh.session-manager.v1`；只保存文件夹、会话 ID→文件夹、展开状态，版本号 1 | Host 配置/数据库可跨设备同步，但增加后端和迁移，不在本版范围 |
| 数据边界 | 文件夹是纯 UI 元数据；创建、导航、重命名、归档、恢复和置顶沿用原生接口 | 改会话格式或移动磁盘目录会破坏 UI-only 约束，未采用 |
| 移动范围 | 同一工作区内，禁止跨工作区、移动到自身/后代；选祖先与后代时后代随祖先一起走 | 跨工作区需要改变真实会话归属，未采用 |
| 排序 | 文件夹按创建顺序；同级会话：置顶优先，再更新时间倒序、ID 稳定打破平局 | 自由排序需要独立排序字段及插入位置交互，未添加 |
| 展开状态 | 工作区/文件夹持久化，默认展开；侧栏窄模式提供展开按钮 | 不复用原生工作区树内部 store，避免两个树结构互相污染 |
| 多选 | Shift 范围按当前可见行；折叠/过滤掉的独立选择项不参与拖动 | 把不可见项目也搬走不易察觉，未采用 |
| 撤销 | 仅移动；改名/展开不被撤销；创建/删除和其他结构改变、跨窗口更新会清空历史 | 全操作撤销涉及原生归档/创建等外部动作回滚，未采用 |
| 删除文件夹 | 删除整棵子树，所有映射清除；会话回工作区根目录，或先安全归档再删除 | 仅提升直接子级容易违背「删除文件夹」预期，未采用 |
| 新会话 | 原生 `sessions.create({workspaceId})` 创建全新 ID，先持久化分组再导航 | `openWorkspace` 会复用空白会话，可能意外移动别处的空白会话，未采用 |
| 视觉 | 原生 Menu、StateDot、文件夹/新建会话/more/pin 图标；14px 标题及原生字体与主题变量，层级色用主题蓝/琥珀/绿 | 不复制整棵原生组件、不新增视觉框架 |
| 原生能力 | 公共 slot priority 覆盖列表；设置中可切回原生；原生重命名及单条归档确认弹窗保留 | 不改安装目录，不直接调用 renderer 错误回退协议 |

### 边界与已知限制

- **按当前浏览器 origin 保存，不跨设备、不跨端口、不保证跨 profile 隔离**。清除该站点存储会删除分组；导出/同步未实现。UI 元数据不含会话正文。更换 Host 后旧 ID 的分组可能不可见，仍保留数据，不自动清理。
- 本版按本机 DSH **0.2.1-rc.2** 源码契约适配。重命名和单条归档通过原生 slot `inject` 闭包取得回调，并非正式独立的 action 服务。上游变更需回归；探测不满足时不覆盖原生树。树中的 pending/未读/运行子会话信号保留，但不是原生行的全部装饰/扩展菜单；需要完整原生功能时切换原生列表。
- 归档隐藏时保留映射，恢复仍归位。若文件夹已被删除，则恢复到根目录。没有工作区的「未分组」只能展示已有会话，不能创建文件夹或接收拖动。
- 批量归档**不强制停止正在运行的任务**。如果某条归档失败，保留文件夹及所有映射并报告错误；先前成功归档的项目可能已隐藏，之后可恢复。外部归档与本地元数据写入不构成一个事务。
- 新会话创建成功后若本地持久化失败，会留下未被打开的原生空白会话，不删除或重试创建，避免误伤草稿。先修复存储后再操作。
- 存储校验/写入失败不覆盖旧状态；启动时损坏会保留原生列表，并记录控制台错误。跨窗口写入前比对已读原始值，检测冲突后先加载新状态并要求重试；`localStorage` 无事务 CAS，不能消除真正同时写入的竞态。请避免两窗口同时整理分组。
- 恢复/置顶仍使用 DSH 原生属性；本插件不改它们的全局存储方式，只改变树中的排列。

### 安装后的人工验收

使用可丢弃的测试会话：

1. 建 A/B 文件夹与 A/子级，刷新后层级/展开状态保持；双击文件夹/会话重命名，中文输入法 Enter 不提前提交。
2. Ctrl 选两会话拖入 A，Shift 选择可见范围；拖父文件夹及子项一起移动，不重复拆开；拒绝跨工作区及循环。
3. Ctrl+Z 连续撤销；展开/改名不丢失，输入框的 Ctrl+Z 不被树拦截。
4. 会话在 A 中置顶仍留在 A；归档后隐藏，恢复回 A；删除 A 后恢复到根目录。
5. 删除文件夹的两种选择分别验证；运行中会话批量归档失败应保留文件夹，不强行停止任务。
6. 新建会话得到全新会话，不复用其他文件夹中的空白草稿；单击打开、双击原生改名；pending/运行/完成未读指示可见。
7. 点击搜索或 Ctrl/Cmd+K 留在文件夹视图，标题/工作区/正文检索可用；Esc 返回分组。设置 → 会话管理的开关可即时切换原生/树状列表，重启保留选择，侧栏底部无切换入口。显示归档时混入原列表、文字灰色且恢复前不能打开。禁用插件恢复原生列表。
8. 两窗口普通修改会同步，检测旧写入时要求重试；浏览器存储损坏时不能覆盖坏数据。检查窄侧栏、深层长名称、中文和浅/深主题。
9. 文件夹改名输入自动全选；Esc/关闭按钮/遮罩按原生 Modal 关闭，Enter 保存且输入法选词不提前提交；检查浅/深主题的遮罩、按钮、输入框及父层会话标题与子文件夹图标对齐。
